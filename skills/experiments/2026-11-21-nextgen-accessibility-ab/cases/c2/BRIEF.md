# Case 2: children's medicine dosing, with an Easy Read version

A community health trust publishes guidance on giving liquid paracetamol to
children. Each guidance page links to an Easy Read version. The trust's
content team makes Easy Read versions with an AI writing tool and adds
pictures from a symbol library.

Files: `dosing.html` (the guidance page) and `dosing-easy-read.html` (the Easy
Read version linked from it).

Review them for accessibility.
